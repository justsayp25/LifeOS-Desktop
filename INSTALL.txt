LifeOS install (Windows)

1. Install Node.js (LTS) from https://nodejs.org if you don't have it.
2. Unzip this whole folder somewhere permanent, for example
   C:\Users\<you>\Documents\Code\lifeos-web3
3. Double-click start.bat. The first run makes a file called .env.
   Open .env and set VAULT_PATH to your vault, for example C:\Obsidian\LifeOS
   Then close the window and double-click start.bat again.
4. Your browser opens http://localhost:4100. The sidebar says "vault connected" when it works.
5. Optional, for the Agent chat: install Claude Code, open a terminal, run: claude
   and sign in once.
6. Optional, for a fast natural voice in conversation mode (any browser): double-click setup-voice.bat once.
   It installs a small voice engine and downloads about 700 MB of speech models. Then restart start.bat.

Updating later: unzip a newer package over the same folder. Your .env and your sync
settings (.sync folder) are not in the zip, so they are kept.

The app never deletes files in your vault: removed notes go to 99 Bin.
